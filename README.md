# pamin-runtime

Compute for Pamin modules that run models locally: instruction-set kernel dispatch (AVX2/FMA, NEON, Accelerate), inference devices over ONNX Runtime, per-call thread budgets and a prepared-model cache. Used by [PaminMemory](https://github.com/pamin-labs/PaminMemory).

Status: not released yet; the code is being extracted from PaminMemory's `pamin-index`.
